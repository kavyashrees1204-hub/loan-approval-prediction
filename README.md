# Loan Approval Prediction Model 🏦🤖

This repository contains a Deep Learning Artificial Neural Network (ANN) model built using TensorFlow/Keras to predict loan approval eligibility based on applicant details.

## 📊 Dataset Features
* Gender, Marital Status, Dependents, Education, Self-Employed status
* Applicant & Co-applicant Income
* Loan Amount & Loan Term
* Credit History & Property Area

## 🛠️ Tech Stack & Libraries Used
* **Python**
* **Pandas & NumPy** (Data Preprocessing)
* **Scikit-Learn** (StandardScaler, Train-Test Split, Metrics)
* **TensorFlow / Keras** (Sequential Neural Network model)

## 🎯 Model Performance
* **Test Accuracy:** ~83.74%
* Saved model file format: `loan_approval_model.h5`
